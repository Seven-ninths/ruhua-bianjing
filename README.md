# 入画汴京

《清明上河图》的跨媒介再创作。沿动态长卷浏览城郊、虹桥和街市，点击赶路人、船工或店伙计，进入各自的第一人称情景。观众选择让路，在船上分次放绳，或从柜台后端起茶碗递给客人。动作发生后，画面和故事会随之推进。返回原位后，可以点开对应的「原画依据」。

## 本地体验

保留项目文件和 `assets/` 目录，用现代浏览器打开 `index.html`。页面为静态 HTML、CSS 和 JavaScript，可以离线运行。支持鼠标拖动、触屏滑动、段落跳转和全卷缩略图定位。键盘聚焦长卷后，可用方向键浏览。

进入人物场景后，拖动画面可以环顾。点击下方选项推进情景，放桅时也可以直接向下拖动场景中的「放桅绳」。使用键盘时，可用 Tab 选择操作，按 Enter 执行，或按 Escape 返回长卷。

## 素材

- 原作是故宫博物院藏张择端《清明上河图》卷，藏品号新00087177。[故宫博物院藏品说明](https://www.dpm.org.cn/collection/paint/228226.html)
- 长卷数字图像取自 Wikimedia Commons，文件页标明其公有领域状态。网页使用缩放及 WebP 转换版本。[数字图像及权利说明](https://commons.wikimedia.org/wiki/File:Alongtheriver_QingMing.jpg)
- 人物场景底图、驮货的驴和茶铺顾客图层由 ImageGen 生成。网页用独立图层动画、镜头调度和原创合成环境音呈现场景。依据卡展示原画细节和本作的情景演绎。
