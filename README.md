# 入画汴京

《清明上河图》的跨媒介再创作。沿动态长卷浏览城郊、虹桥和街市，再借赶路人、船工和店伙计的视角感受城郊行路、漕船过桥与街边店铺的一段日常。每段视角随脚步、船行或人物视线连续移动。返回长卷原位后，可以点开对应的「原画依据」。

## 本地体验

保留项目文件和 `assets/` 目录，用现代浏览器打开 `index.html`。页面为静态 HTML、CSS 和 JavaScript，可以离线运行。支持鼠标拖动、触屏滑动、段落跳转和全卷缩略图定位。键盘聚焦长卷后，可用方向键浏览。

进入人物场景后，拖动画面可以环顾，也可以随时停留片刻。将键盘焦点移到画面，可用方向键环顾、空格停留或继续。按 Escape 可返回长卷。

## 素材

- 长卷数字图像取自 Wikimedia Commons，文件页标明其公有领域状态。网页使用缩放及 WebP 转换版本。[数字图像及权利说明](https://commons.wikimedia.org/wiki/File:Alongtheriver_QingMing.jpg)
- 人物场景底图和茶铺顾客图层由 ImageGen 生成。网页用连续的第一人称镜头、独立图层动画和原创合成环境音呈现场景。依据卡展示原画细节和本作的情景演绎。
