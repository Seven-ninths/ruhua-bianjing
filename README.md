# 入画汴京

《清明上河图》的跨媒介再创作。沿动态长卷浏览城郊、虹桥和街市，点画中人物或长卷上方的按钮进入他的视角。每段视角随脚步、船行或人物视线连续移动。到达后可以直接对照原画与场景演绎、再体验一次，或回到长卷原位。

长卷里几处原画人物会轻微迈步、探身或抬手，岸边和桥下的水纹随水流轻动。赶路人从篱笆口走到河湾，前方的背篓行人跟着土路走远。虹桥一段从桥下水声开始，经过几次松绳放桅，再驶进开阔的水面。店伙计在柜台后站定片刻，接着走到铺口，目送街边的大人和孩子往远处走去。

## 本地体验

克隆仓库或下载 ZIP 并解压，用现代浏览器打开 `index.html`。项目使用静态 HTML、CSS 和 JavaScript，包含在本地运行所需的图片和音频。支持鼠标拖动、触屏滑动、段落跳转和全卷缩略图定位。键盘聚焦长卷后，可用方向键浏览。

进入人物场景后，拖动画面可以环顾，也可以随时停留片刻。将键盘焦点移到画面，可用方向键环顾、空格停留或继续。按 Escape 可返回长卷。

## 素材

- 原作是故宫博物院藏张择端《清明上河图》卷，藏品号新00087177。[故宫博物院藏品说明](https://www.dpm.org.cn/collection/paint/228226.html)
- 长卷数字图像取自 Wikimedia Commons，文件页标明其公有领域状态。网页使用缩放及 WebP 转换版本。[数字图像及权利说明](https://commons.wikimedia.org/wiki/File:Alongtheriver_QingMing.jpg)
- 人物场景底图由 ImageGen 生成。人物和船只用原场景中的笔触制作，甲板与行人移开后露出的河面和街面由 ImageGen 补绘。分层画面配合连续的第一人称镜头和原创合成环境音。依据卡展示原画细节和本作的情景演绎。
